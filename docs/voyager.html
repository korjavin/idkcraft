Voyager: бот, который сам пишет себе навыки

Что это за идея, почему она работает и как мы переносим её в idkcraft (эпик vf8e)

Коротко. Voyager (NVIDIA и Caltech, 2023) — агент для Minecraft на GPT-4. Веса модели он не обучает. Вместо этого он пишет программы: на каждую новую задачу LLM пишет JavaScript-функцию для mineflayer (той же библиотеки, на которой сделан наш бот). Код запускается в игре, ошибки и результат возвращаются модели, и она правит код, пока задача не будет выполнена. Удачная функция кладётся в библиотеку навыков и дальше используется как кирпичик для более сложных навыков. Бот «учится» тем, что копит проверенный код.

1. Три роли и библиотека

Curriculum — «учитель»

Что делать дальше?

Смотрит на инвентарь, биом, список уже освоенного и проваленного и предлагает следующую задачу: «добудь 3 железа», «сделай каменную кирку». Задача должна быть чуть сложнее того, что бот уже умеет.
Action agent — «программист»

Как это сделать?

Пишет одну функцию async function mineIron(bot) поверх mineflayer, pathfinder и collectblock. В подсказку ему кладут пять самых похожих навыков из библиотеки, чтобы он их вызывал, а не писал всё с нуля.
Critic — «проверяющий»

Получилось?

Ещё один вызов GPT-4 по инвентарю и событиям решает, выполнена ли задача. Если нет, объясняет, чего не хватает. Например: «кирки нет, сначала скрафти палки».
Skill library. Векторная база: описание навыка → его код. Проверенный критиком навык записывается туда навсегда. Сложные навыки вызывают простые (craftIronPickaxe вызывает mineIron и smeltOre), поэтому библиотека растёт как дерево. Отсюда и название: бот уходит всё дальше по технологическому дереву Minecraft.

2. Цикл обучения

Как выглядит «навык»

// написано моделью, проверено критиком, лежит в библиотеке
async function craftStonePickaxe(bot) {
  await mineBlock(bot, "cobblestone", 3);      // ← навык из библиотеки
  await craftItem(bot, "stick", 1);            // ← навык из библиотеки
  const table = await placeCraftingTable(bot); // ← навык из библиотеки
  await craftItem(bot, "stone_pickaxe", 1, table);
  bot.chat("stone pickaxe ready");
}

Именно в этом сила идеи. Действие записано кодом, а не нажатиями клавиш, поэтому его можно переиспользовать, комбинировать и читать. Вызовы проверенных навыков выглядят у модели как новые слова языка.

3. Что показали авторы

Результаты

  • В 3,3 раза больше уникальных предметов, чем у прежних LLM-агентов.
  • До каменных и железных инструментов в 9–15 раз быстрее.
  • Единственный из сравнённых агентов, который добрался до алмазных инструментов.
  • Библиотека переносится в новый мир, и там он решает новые задачи без повторного обучения.

Абляции: что важно

  • Без критика результат падает сильнее всего. Модель уверенно врёт себе, что задача выполнена.
  • Без библиотеки прогресс выходит на плато: каждое умение каждый раз пишется заново.
  • Без обратной связи от среды (ошибки, лог) код не чинится.
  • GPT-3.5 вместо GPT-4 не справляется: нужна сильная модель.

6. Наш цикл: учимся офлайн, на проде — только проверенное

Главное отличие от Voyager: учёба отделена от прода. Модель пишет и чинит навыки только на ноутбучном стенде. В игру с детьми попадает лишь то, что прошло стенд, ревью и обычный PR.

И вторая половина — приказы словами (vf8e.6)

Модель не пишет здесь код и не сидит в тике. Один раз на приказ она раскладывает свободную фразу на последовательность того, что бот уже умеет. Исполняет всё обычный проверенный механизм.

Твои решения от 18.10: цикл крутится на нашем Messages-API-коде с ключом из stash, а не через claude -p. Навыки разрешены и для восстановления, и для шагов цели. Учёба идёт на ноутбуке. Бюджет: 3 задачи × до 6 попыток с отчётом по токенам.

«Что работает — продолжает работать.» Всё новое стоит за флагами, выключенными по умолчанию: текущий бот байт-в-байт тот же, пока флаг не включён.
